## 3. 파이프라인별 생성 방식

### FLOW_VEO (H01, H03)
- 원래 뜻: Google Flow/Veo 로 사람 움직임 영상. **연결이 없어 대체 경로 필요 (결정 D1).**
- 방식: 시작 이미지 → 사진→영상. 문장은 **움직임과 카메라만** 적는다 (장면 묘사는 시작 이미지가 담당). 무음.
- H03 은 먼저 시작 사진 1장 (AI 사진, 2 credits) → 사람 확인 → 영상.

### BLENDER_FLOW (H02, H02b, H04, H05)
- 원래 뜻: Blender 로 공간·카메라를 먼저 잡고 → Flow/Veo 영상.
- **현재 Blender 연결 없음 (P7).** 임시 방식 제안 (결정 D3): 승인된 기준 그림이 공간 기준 역할 + 카메라 초안 JSON 값(렌즈·높이·움직임)을 문장으로 → 사진→영상.
- 공간 오류(봉분 크기, 인물 위치, 층 순서)가 2번 연속 나오면 그 샷만 Blender 사전 작업으로 전환 (사람 결정).

### AI_STILL (H06, H07)
- Nano Banana Pro 사진 1장 + 편집에서 느린 줌.
- H06: 기준 그림 S06-B 참조, 봉분 비율(폭이 높이의 약 3.7배) 문장 명시.
- H07: 현장 SH003 촬영 후, 그 구도 값(LOC_CHEONMACHONG match_cut_frame)으로 문장 작성.

## 5. 비용 기록 방식

- 지금과 같다: 호출 1회 = `generation` 기록 1개 + `provider_jobs/HF_<job>.json` (실제 전송 문장) + `cost` 파일 크레딧 합계.
- 영상은 `stage = VIDEO`, `duration_sec` 기록.
- 공용 계정이므로 소진은 잔액 차이가 아니라 job 기록 합계로 계산 (D-018). 호출 직후 거래 내역과 대조, 출처 불명 차감은 제외하고 메모.
- Google Flow 를 수동으로 쓰게 되면: 원화/Flow 크레딧을 별도 통화로 기록하고, 사람이 보낸 문장 원문·결과 파일·화면 캡처를 증빙으로 남긴다 (job API 없음).
- Money Gate 경고: 원화 환산 확정 후 80% 경고 · 95% 강경고 · 100% 잠금.

## 6. 실패 시 KEEP / CHANGE

- 한 샷이 실패하면 **실패 항목만** 바꾼 새 prompt 버전 + PATCH 를 먼저 저장 → 그대로 전송 (D-016).
- 영상은 부분 편집이 어려우므로 재생성하되, 문장에서 바뀌는 곳은 실패 항목뿐이어야 한다.
- 실패 분류: CAMERA(움직임 방향·속도) · MOTION(부자연 동작) · CHARACTER_IDENTITY(원로 얼굴·복식 흔들림) · ARCHITECTURE(봉분·목곽 형태·층 순서) · HISTORICAL_ISSUE(시대 위반 물건) · AI_ARTIFACT(손가락·물체 녹아내림).
- **같은 샷 2번 연속 실패 → 멈추고 사람에게 방법 전환 제안** (편집 반복·재생성 반복 금지, S04·시종 교훈).
- 사소한 흠(뒤쪽 소품 등)은 와이드 샷이면 허용 여부를 사람에게 묻고, 추가 생성은 기본 금지.
