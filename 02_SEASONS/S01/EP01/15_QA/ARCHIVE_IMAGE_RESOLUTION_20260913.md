### 동일 유물 확인

- **유리잔**: 국립경주박물관 소장품 DB(mng_no=46)에 "경주2386 / 보물 / 출토지 천마총"이 명시되어 있다. e뮤지엄 레코드도 "경주2386번 / 보물 / 국립경주박물관 / #천마총"이다. 축소본 육안 비교에서도 세로 골 무늬 상단과 벌집형 하단을 가진 청색 유리잔으로, 전시 해설 사진(613×816)과 같은 유물·같은 촬영 계열이다. 참고로 소장품 DB 사진(668×515)은 같은 유리잔의 오래된 다른 촬영본이다.
- **말다래**: 전시 해설 페이지가 "경주2309 / 대나무, 금동판 / 천마총"이다. e뮤지엄은 "경주2309번 / 透彫金銅板竹心被障泥(투조 금동판 죽심 피장니 = 대나무심 금동판 투조 말다래) / 금동"이다. 축소본 비교 결과, e뮤지엄 3000×1933 이미지는 전시 해설 800×515 이미지와 **같은 사진**이다(대나무 편물 바탕, 청록 녹이 슨 금동 테두리, 중앙의 금빛 천마 조각).
- 천마그림 말다래 Ⅰ/Ⅱ(전시 페이지 mng_no=298/299, 백화수피제)와 국보 천마도(RTS_WIKI_CHEONMADO_001)는 **다른 유물**이다.
- e뮤지엄 출토지 칸은 두 유물 모두 "경상북도-경주시"까지만 적혀 있어 "천마총"이 필드로는 없다. 천마총 출토는 같은 유물번호의 국립경주박물관 페이지(유리잔: 소장품 DB 출토지 칸, 말다래: 전시 해설 키워드/설명)로 교차 확인했다.

## 4. 확인하지 못한 것 (솔직하게)

1. **e뮤지엄 "이미지 다운로드" 실제 파일**: 페이지 JS는 표시 이미지 경로 `/IMG/…`를 `/IMG/DOWN/…`(전체는 `/IMG/DOWNS/…`)로 바꿔 GET 폼을 제출한다. curl 재현 결과 400/405 HTML 응답이 와서, 다운로드 파일이 표시 이미지(3000 px)보다 큰지는 **확인 못 함**. 3000 px 수치는 상세 페이지가 세션 쿠키로 직접 제공한 이미지를 받아 잰 값이다.
2. **e뮤지엄 검색**: `/search`, `/m/search`가 curl과 WebFetch 모두에서 HTTP 500이었다. relicId는 "PS01 + 국립경주박물관 코드 00100200 1 + 유물번호 6자리 + 00000" 규칙을 추정해 직접 열었다(두 번호 모두 적중, 유물번호 필드 일치 확인). 같은 유물의 **다른 e뮤지엄 레코드**(예: 부속번호가 다른 레코드)가 더 있는지는 검색이 안 되어 확인 못 함.
3. **국립중앙박물관 소장품 검색**: GET 파라미터(keyword/searchWord/query 등)가 필터로 먹지 않아 항상 전체 207,494건이 나왔다. 두 유물은 국립경주박물관 소장이라 국립중앙박물관 소장품 DB에는 없을 가능성이 높지만 **검증은 못 함**. 찾은 것은 알림 게시물(3유형)뿐이다.
4. e뮤지엄 이미지 저작권 라벨은 페이지 단위 문구다. 촬영자가 별도로 표기되어 있는지는 확인하지 않았다.
5. proof 캡처는 만들지 않았다(이번 작업 범위: 보고서 1개).
