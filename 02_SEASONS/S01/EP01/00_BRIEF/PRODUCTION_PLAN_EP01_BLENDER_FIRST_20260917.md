## 0. 한 줄 순서

**FACT 치수표 → Blender 마스터 씬 1개(천마총 축조 현장, 실측 스케일) → 샷별 카메라 배치 → 클레이 렌더 + 깊이 패스 → Higgsfield 이미지→이미지 실사화(기하 유지) → 검수 3단 → 정지 컷 확정 → 패럴랙스·숫자 오버레이·내레이션으로 롱폼 편집 → 같은 .blend 에 9:16 카메라 추가해 쇼츠 파생.**

## 1. 왜 Blender 가 먼저인가

- 지금까지 재연 컷은 컷마다 AI 가 공간을 새로 지어 **봉분 크기·비계·돌무지가 컷마다 달랐다** (H01~H05 연속성 문제의 뿌리).
- Blender 씬 하나에 47 m × 12.7 m 봉분, 6.6 × 4.2 m 목곽, 2.15 × 0.8 m 관을 실측으로 놓으면 **모든 컷의 스케일·광원·배치가 자동으로 맞는다** (연속성 락 ①②③: 이동 벡터·광원·시각 시계).
- 도해(G04 단면·G05 축조 4단계·G14 치수)와 재연 컷이 **같은 기하**에서 나오므로 숫자와 그림이 어긋나지 않는다.
- 같은 씬에서 세로 카메라만 추가하면 쇼츠 컷이 공짜로 나온다.

## 2. 단계

### Phase 0 — 치수·배치 잠금 (무료, 오늘)
- 산출 `10_BLENDER/SCENE_SPEC_CHEONMACHONG_V01.md`: 모든 치수에 fact_id. 
  - 봉분 최종 지름 47 m · 높이 12.7 m (`CLM_EP01_STRUCT_004`, FACT)
  - 목곽 6.6 × 4.2 m, 관 2.15 × 0.8 m (`CLM_EP01_STRUCT_004`, FACT) · 층 순서 관→목곽→돌→흙 (`CLM_CHEONMACHONG_LAYOUT_001`)
  - 목곽 높이·돌무지 두께·비계 형태·작업 인원 = **INTERPRETIVE** (FACT 없음 → 화면 라벨 "reconstruction", 숫자 표기 금지)
  - 축조 단계 4 (G05): 목곽 설치 → 돌 쌓기 → 봉토 → 완성. 각 단계의 봉분 높이 = "시각 시계".
  - 광원: 오후 늦은 태양 카메라-좌 45° (BIBLE §1), 씬 전체 고정.
- 카메라 목록: 기존 `10_BLENDER/camera_*.json` 8개 + G04·G05·G14 도해 카메라 + 쇼츠 9:16 카메라 3개.

### Phase 1 — Blender 마스터 씬 (무료, 봇이 bpy 스크립트로 생성, 1~2일)
- 파일 `04_BLENDER_LIBRARY/scenes/EP01_CHEONMACHONG_MASTER_V01.blend` (git 미추적, 경로만 기록) + 생성 스크립트 `tools/blender/build_cheonmachong.py` (git 추적 — 씬은 언제든 재생성 가능).
- 구성: 지형(완만한 평지 + 원경 구릉) · 봉분 4단계(오브젝트 4개, 단계별 표시) · 목곽·관·돌무지(파티클) · 목재 비계 · 인물 프록시(키 1.72/1.67 m 마네킹, 위치·시선만) · 태양 · 카메라 컬렉션.
- 렌더 패스: ① 클레이(회색, 그림자 포함) ② 깊이(Z, 패럴랙스용) ③ 선화(GT 도해용, Freestyle) ④ 치수선 레이어(GT-03).
- 검수: 스케일 자(10 m 막대) 렌더 1장으로 치수 확인.

### Phase 2 — 도해 컷 확정 (무료)
- G04 단면 컷어웨이, G05 축조 4단계, G03 왕릉군 개념도, **G14 MEASURE ×6** (신설: 봉분 47/12.7 m 치수선, 목곽, 관, 유물 11,526점, 1973 발굴, 비교물 12.7 m ≈ 4층). 전부 Blender 선화 + 편집 자막. AI 0.
- 사용자 OK → ORIGINAL_GRAPHIC 11샷 중 해당분 확정.

### Phase 3 — 재연 컷 실사화 (Higgsfield, 컷당 2 credits, 승인 필요)
- 대상: 과거 재연 8컷 (H01~H07 + S06 축조 마스터). 현재 시점 사진 컷 10장(승인분)은 그대로.
- 방법: Nano Banana Pro `image_references` = [Blender 클레이 렌더(구도·기하), 원로 마스터팩 V07(얼굴·복식), 필요 시 실제 지형 사진]. 프롬프트 규칙: "구도·기하·광원은 렌더 그대로, 재질·인물만 실사화". 인물은 정지.
- 검수 3단 + 복식 체크리스트 5. 기하가 틀어지면 패치(인페인트), 재생성 아님.
- 예산: 8컷 × 2회 = 32 credits 이내 (D-051 잔여 74 안).

### Phase 4 — 롱폼 편집 (무료)
- 깊이 패스로 DepthFlow 패럴랙스(4배 업스케일 규칙), G14 숫자 오버레이, 내레이션 wav(Grady), 그레이드 LUT 1개.
- `tools/assemble_rough_cut.py` (ffmpeg): 타임라인 JSON → 컷 + 오버레이 + 내레이션 + 자막 자동 조립 → 러프컷 v2.
- 사용자 검수 1분 단위.

### Phase 5 — 쇼츠 파생 (무료 + 필요 시 2~4 credits)
- 같은 .blend 에 9:16 카메라 3개 (단면 클로즈·봉분 수직·목곽 위에서).
- 쇼츠 S2 확장: "47 metres. No machines." 60초 건축 쇼츠 = 숫자 콜드오픈 → 반전 한 줄("무덤이 아니라 돌 산") → 3단계(목곽·돌·흙, 단계마다 숫자 1) → 질문 회귀. 소재 = Phase 2·3 산출 재사용.
