## 1. 사람 게이트 (최우선)
- **봇은 어떤 댓글·포스트도 직접 게시하지 않는다.** 봇 산출 = 초안 md. 게시·답글은 사용자 (`channel.json.cta_policy.bot_may_post = false`).
- 답글 초안은 출처 없는 역사 주장 금지 (HISTORY_ACCURACY). 정정 댓글(`CORRECTION`) 은 Fact Check Agent 검토 뒤에만 답한다.

## 2. 게시 시 (자료집: 댓글유도)
고정 댓글 1개 = 시청자에게 되묻는 질문 1개 + 출처 링크 1줄. 구독 요청은 넣지 않는다 (설명란 CTA 와 분리).

## 3. 후속 (자료집: 후속메시지 · 재참여메시지)
| 시점 | 행동 | 담당 |
|---|---|---|
| D+1 | 커뮤니티 탭 포스트: 도해 1장(GT-0x) + 출처 1개 + 댓글 질문 중 1개 되묻기 | Community Agent 초안 → 사용자 게시 |
| D+7 | 댓글 수확 2차, `QUESTION` 상위 3개를 다음 에피 후보로 | Analytics → Strategy |
| 다음 에피 게시 시 | 이전 에피 고정 댓글에 새 에피 링크 갱신 (재참여) | Community Agent 초안 → 사용자 |

## 4. 답글 원칙
- 질문에는 답 + 출처 1개. 칭찬에는 짧게. 스팸은 무응답(사용자 판단).
- 논쟁·역사 해석 이견은 "우리는 X 등급(FACT/INTERPRETIVE)으로 표시했다" 로 답하고 대본을 고치지 않는다 (사용자 D-번호 없이 해석 변경 금지).

## 5. 담당
**Community Agent** (신규, Publish & Learning Engine) — 담당: 고정 댓글·커뮤니티 포스트·답글 초안 / 금지: 자동 게시 · 출처 없는 답변 · 해석 변경.
