경주 현장 촬영 체크리스트

결론: 현재의 경주·대릉원·천마총은 우리가 직접 촬영하는 게 가장 좋다. 실제 장소감이 생기고 저작권 문제도 크게 줄어든다.

이번 촬영의 핵심

영상 전체에서 “지금의 경주”가 현실의 기준점이 된다. 과거 장면은 Higgsfield가 맡더라도, 현재의 경주는 반드시 실제 풍경과 생활감으로 잡는다.

MUST HAVE 현대 거리 + 왕릉이 한 프레임에 보이는 컷 / 대릉원 와이드 / 천마총 외관 / 사람과 봉분 크기 비교 / 해질녘 클로징

1. 오프닝

  1. 평범한 경주 도로·보행자
  2. 카페나 상점 뒤로 봉분이 보이는 컷
  3. 건물/나무 뒤에서 왕릉이 드러나는 리빌
  4. 현대 거리 + 봉분 같은 프레임
  5. 사람이 지나가며 봉분 크기를 느끼게 하는 컷

각 8~15초, 6~10컷 목표.

2. 대릉원

  1. 왕릉 여러 기가 겹쳐 보이는 와이드
  2. 왕릉 사이 산책로
  3. 낮은 앵글의 봉분과 하늘
  4. 사람/나무와 비교되는 크기
  5. 해 질 무렵 옆빛 받는 봉분
  6. 조용한 빈 길과 바람

12~15컷 목표.

3. 천마총

  1. 천마총 표지
  2. 외부 봉분
  3. 입구로 접근하는 이동 컷
  4. 관람객 출입
  5. 입구 디테일
  6. 내부 촬영은 현장 규정 확인 후 진행

외부 6~8컷은 반드시 확보.

4. 현대 경주와의 대비

  1. 카페·식당 거리 + 왕릉
  2. 차량/버스 + 왕릉
  3. 사진 찍는 관광객
  4. 가족·커플 산책
  5. 스마트폰으로 왕릉 찍는 장면
  6. 석양/저녁 마지막 와이드

5. 편집용 B-roll

  1. 잔디와 바람
  2. 발걸음
  3. 나뭇잎과 봉분
  4. 표지판
  5. 벤치·빈 길
  6. 입장 동선 디테일
  7. 그림자 움직임

6. 사진도 같이

  1. 가로 왕릉 와이드 5장
  2. 세로 3장 — Shorts/썸네일 대비
  3. 천마총 외관 3장
  4. 현대 도시 + 왕릉 3장
  5. 제목 넣을 여백 있는 사진 2~3장

촬영 규칙

  • 가능하면 4K.
  • 일반 컷 24/25/30fps, 슬로모션용만 50/60fps.
  • 한 구도 최소 8초 이상 유지.
  • 각 장소에서 깨끗한 현장음 10~20초 녹음.
  • 와이드 / 미디엄 / 디테일 세 가지로 반복 촬영.
  • 세로 영상도 따로 찍는다.
  • 낯선 사람 얼굴을 주인공처럼 크게 잡지 않는다.

권장 촬영 순서

  1. 아침 — 사람이 적을 때 현대 거리 + 대릉원 와이드
  2. 오전 — 천마총 외관/입구
  3. 낮 — 표지판·텍스처·보충 B-roll
  4. 오후 — 현대 도시 대비 컷
  5. 골든아워 — 왕릉 히어로 컷
  6. 해질녘 — 엔딩용 현대/고대 대비
중요: 운영시간·촬영규정·내부촬영·드론은 촬영 당일 최신 공식 안내를 다시 확인한다. 박물관 내부 영상은 일반 관람 사진과 별개로 상업적 영상 제작 허가가 필요할 수 있으므로 따로 확인한다.
