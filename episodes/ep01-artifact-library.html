천마총 유물 소스 라이브러리

수익화 영상에서 쓰기 좋은 공공누리 제1유형 중심의 공식 유물 자료를 선별.

라이선스 기준: 공공누리 제1유형은 출처표시 조건으로 상업적·비상업적 이용과 2차적 저작물 작성이 가능하다. 국립경주박물관 저작권 정책도 제1유형 표시 자료를 확인한 뒤 자유이용하라고 안내한다.

1. 천마총 금관

KOGL TYPE 1

천마총 금관

출토지: 천마총 · 높이 32.5cm · 신라 지배자를 상징하는 대표 위세품.

영상 역할: 3:15–4:20 권위·위세품 설명 / 5:20–6:05 “박물관 전시품 이전에 장례의 일부였다” 장면.

공식 원본 페이지 →

2. 천마총 금허리띠

OFFICIAL SOURCE

천마총 금허리띠

44개 띠꾸미개와 13줄 띠드리개. 물고기, 작은 칼, 족집게, 곱은옥, 숫돌을 본뜬 장식 등 다양한 요소가 달린다.

영상 역할: 금관만 보여주는 단조로움을 피하고 “지위와 정체성이 여러 물건을 통해 표현되었다”를 보여줄 때.

공식 페이지 →

3. 천마총 가슴걸이

KOGL TYPE 1

가슴걸이

천마총 출토. 금·구슬·옥으로 구성되며 박물관 설명은 신라 지배계층의 상징적 껴묻거리로 소개한다.

영상 역할: 3:15–4:20 “status was deliberately made visible” 내레이션에 적합.

공식 페이지 →

4. 천마총 유리잔

KOGL TYPE 1

유리잔

천마총 출토, 신라 6세기. 금제품 외에도 귀중한 유리 제품이 부장되었음을 보여준다.

영상 역할: 0:35–1:25 “gold, glass, fine objects” 문장과 3:15–4:20 부장품 다양성 장면.

공식 페이지 →

5. 유리구슬 목걸이

KOGL TYPE 1

천마총 유리구슬

천마총에서 5,500여 점의 유리구슬이 출토되었다는 박물관 설명이 있다.

영상 역할: “more than eleven thousand objects” 직후 빠른 디테일 몽타주.

공식 페이지 →

6. 천마그림 말다래 I

KOGL TYPE 1

천마도

자작나무 껍질 바탕에 천마가 그려진 말다래. 천마총 명칭의 핵심 유물.

영상 역할: 1:25–2:15 천마총 이름의 유래 설명. AI 재현보다 실제 유물을 먼저 보여주는 기준 장면.

공식 페이지 →

7. 천마무늬 말다래

KOGL TYPE 1

금동 장식 말다래

대나무살·천·금동판으로 만든 말갖춤. 천마총의 말 문화와 장식 마구를 보여준다.

영상 역할: 0:35–1:25 horse equipment 언급 / 3:15–4:20 엘리트 장례 물품의 범위 확대.

8. 금제 관모

KOGL TYPE 1

천마총 금제 관모

천마총 출토. 박물관은 금관과 함께 지배자를 상징하는 위세품으로 설명한다.

영상 역할: 금관 하나에만 권위 해석이 집중되지 않도록 보조 증거로 사용.
